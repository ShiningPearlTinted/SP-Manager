# SP-Manager FastReport Bridge

This bridge uses the **actual FastReport .NET engine** and the supplied Aronium `ProductsPriceTags.frx` template.

- FastReport endpoint: `http://127.0.0.1:18766`
- Status: `/status`
- Price Tags PDF: `POST /price-tags/pdf`
- Template: `fastreport/ProductsPriceTags.frx`
- Assemblies: `fastreport/FastReport.dll`, `FastReport.Bars.dll`, `FastReport.SQLite.dll`

The normal SP-Manager Local Agent starts this bridge automatically on Windows PowerShell.

The browser preview is the PDF generated by FastReport, so barcode rendering and human-readable barcode text come from FastReport rather than the previous SVG approximation.
