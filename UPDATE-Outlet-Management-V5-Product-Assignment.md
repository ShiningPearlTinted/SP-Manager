# SP-Manager 1.0.38 — Outlet Management V5

## Scope
- Add Product Assignment from one outlet to another.
- Target product is created under the target outlet.
- Target stock starts at 0. Price/cost/product settings are copied.
- Category/group are resolved by name for the target outlet.
- Existing sales are not changed.
- Explicit assignment dialog with Yes/No confirmation.
- No changes to POS transaction calculations, payment flow, customer flow, purchases, reports or existing Outlet Master CRUD.

## Validation
- main.jsx parser/transpile check required.
- PHP syntax check for api/products.php required.
