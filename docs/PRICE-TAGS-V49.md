# Price Tags V49

LOCK update only for Price Tags barcode rendering.

- Human-readable barcode value is always shown below every barcode type.
- Barcode type name is always shown below the value.
- Arial Regular is used for barcode labels.
- Barcode Height is applied as a real millimetre height in preview and raw ZPL/TSPL output.
- When barcode height is taller than the configured label height, the effective rendered label height expands automatically so the barcode labels are not clipped.
- Other POS functions remain unchanged.
