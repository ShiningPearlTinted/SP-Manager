# SP-Manager V46 — Price Tags

- Modern dark Price Tags UI based on the approved mockup.
- Barcode human-readable text uses Arial, regular weight.
- Every barcode type shows the human-readable value and a barcode type label underneath.
- Print preview button opens the browser print review dialog.
- Save as PDF button opens the same print review flow so the browser can choose Save as PDF.
- Existing ZPL/TSPL raw printing and product-selection modes are retained.
- Other POS functions are locked and unchanged.
