# SP-Manager V45 - Price Tags

Price Tags only update based on the existing Aronium-style layout.

- Large, readable barcode with human-readable value below.
- Barcode height constrained to label height so the value is not clipped.
- Product selector modes: All products/name search, Barcode search, Code search, Selected products.
- Product result list with checkboxes.
- Group filter, Select all and Clear operate on current filtered candidates.
- Existing ZPL/TSPL printer output retained.
- Other POS functions are unchanged.
