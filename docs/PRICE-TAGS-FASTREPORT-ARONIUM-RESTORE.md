# Price Tags — Aronium/FastReport Restore

This build restores the Price Tags workflow to the Aronium-style layout:

- Layout / Display / Products sections
- A4/A5/Letter/Custom page settings
- 50 x 50 mm default label size
- 2-column default layout
- Product name / price / SKU / barcode / tax-inclusive / borders
- Barcode type and size controls
- Product search/selection and copies
- FastReport-style preview toolbar with page navigation and zoom
- Actual FastReport .NET engine using the supplied Aronium `ProductsPriceTags.frx`

The browser only displays the PDF generated by FastReport. The report itself is not recreated in HTML/SVG.
