# POS / Sales Module — Phase 1

Implemented UI workflow:

- Product search / barcode field
- Product catalogue
- Add product to order
- Increase / decrease quantity
- Remove item
- Customer selection
- Percentage discount
- Automatic subtotal / discount / total calculation
- Payment type selection
- Complete sale action
- Backend sales endpoint foundation
