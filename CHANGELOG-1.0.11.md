# SP-Manager 1.0.11

- Quantity dialog: removed the `ORDER ITEM` label.
- Quantity dialog: removed the helper text `Enter the quantity for the selected item.`.
- Quantity input: removed browser number up/down spinner controls while keeping numeric input behavior.
- Customer Master: Delete action now opens a custom Yes/No confirmation message box before deleting.
- Customer delete behavior remains the same after confirmation; Walk-in Customer remains protected.
